# ADR-005: HTTP-сервисы 1С с JWT

## Статус
Accepted

## Контекст
1С должна предоставлять данные (сальдо ЕНС, начисления, документы) внешнему оркестратору. Связано с **TM-01** (Tampering / искажение финансовых данных). Покрывает **NFR-SEC-006**, **NFR-004**. Альтернативы: (1) COM-соединение (только Windows, не работает с учебной версией), (2) прямая работа с БД 1С (опасно, ломает учёт), (3) HTTP-сервисы 1С с аутентификацией.

## Решение
HTTP-сервисы 1С (`GET /api/v1/taxes/balance`, `POST /api/v1/taxes/calculate`, `GET /api/v1/documents/search`) с аутентификацией по JWT. **Только чтение** (кроме `calculate`, который не пишет в БД). HTTPS обязателен. Таймаут вызова — 5 секунд. При недоступности 1С — fallback на ответ только по НК РФ (FR-002, scenario «1С недоступна»).

## Последствия

**Плюсы:**
- Работает с учебной и Комьюнити-версией 1С (в отличие от COM).
- Безопасность: JWT + HTTPS (TM-01, NFR-SEC-006).
- Не ломает учёт (только чтение).
- Стандартный подход для веб-интеграций.

**Минусы:**
- Требуется публикация HTTP-сервисов в 1С (настройка).
- JWT нужно выпускать и ротировать (дополнительный компонент).
- Таймаут 5 сек → при медленной 1С пользователь получит неполный ответ.

**Риски:**
- Искажение данных через API → **Митигация:** только чтение + JWT (T-304).
- 1С недоступна → **Митигация:** fallback на RAG-only ответ (T-204).

**Влияние на наблюдаемость:**
- Добавлен сигнал `1c.api.duration` с `endpoint`, `status_code`, `trace_id` (OBS-C-01).
- Добавлен span `1c.api.call` с `endpoint`, `status_code`, `duration_ms`, `trace_id` (OBS-C-02).
- Добавлен лог `1c.api.called` с `endpoint`, `status_code`, `duration_ms`, `trace_id` (OBS-C-01).
- **Влияние на OBS-C-01…06:** OBS-C-01 (покрытие FR-002), OBS-C-02 (traceparent в 1С-вызовах), OBS-C-03 (SLO availability привязан к `1c.api.duration`).

## Альтернативы
| Альтернатива | Отклонена | Причина |
|---|---|---|
| COM-соединение | Да | Только Windows; не работает с учебной 1С |
| Прямая работа с БД 1С | Да | Ломает учёт; небезопасно |
| Без JWT (только HTTPS) | Да | Не покрывает TM-01 (аутентификация) |
