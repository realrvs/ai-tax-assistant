# ADR-004: Аудит запросов/ответов (90 дней)

## Статус
Accepted

## Контекст
Нужно доказательство действий пользователя (**TM-02** Repudiation) и прозрачность работы ассистента для разбора ошибок. Также требуется защита от PII в телеметрии (**TM-06**, **TM-09**). Покрывает **NFR-SEC-004**, **NFR-OBS-004**. Связано с **OBS-C-04** (redaction) и **OBS-C-05** (verification).

## Решение
Все запросы и ответы логируются в собственный аудит-лог: `user_id` (Telegram + 1С), `timestamp`, запрос, выбранные источники (RAG/1С), ответ, ссылки на НК РФ и 1С, `trace_id`. Логи хранятся **90 дней**. Формат — JSON Lines. Доступ к логам — только администратор. Автоматическая ротация: каждый день удаляются записи старше 90 дней (с возможностью архивации).

## Последствия

**Плюсы:**
- Аудит и прозрачность (TM-02, NFR-SEC-004).
- Возможность анализа ошибок и улучшения RAG/классификатора.
- Доказательство действий при спорах.
- 90 дней — баланс между полезностью и минимизацией риска утечки PII.

**Минусы:**
- Дополнительное хранилище (оценка: ~1 МБ на 1000 запросов).
- Требуется защита логов (содержат PII и финансовые данные).
- 90 дней хранения → нужна ротация и удаление старых логов.
- Через 90 дней нельзя разобрать старый инцидент → нужен архив.

**Риски:**
- PII в логах без redaction → **Митигация:** redaction processor + `security.pii.redacted` (T-303, T-404, TC-OBS-006).
- Ротация не работает → **Митигация:** тест TC-OBS-006 (T-303).

**Влияние на наблюдаемость:**
- Добавлен лог `audit.entry` с `user_id`, `sources`, `answer.length`, `trace_id` (OBS-C-01).
- Добавлен лог `security.pii.redacted` с `field.name`, `trace_id` (OBS-C-04).
- **Влияние на OBS-C-01…06:** OBS-C-01 (покрытие FR-006), OBS-C-04 (redaction PII), OBS-C-05 (verification в apply.md).

## Альтернативы
| Альтернатива | Отклонена | Причина |
|---|---|---|
| Без аудита | Да | Не покрывает TM-02 |
| Только логи Telegram | Да | Нет привязки к 1С-пользователю и источникам |
| Хранить бессрочно | Да | Риск утечки PII (152-ФЗ) |
| Хранить 30 дней | Да | Недостаточно для анализа ошибок |
| Хранить 1 год | Да | Избыточно для MVP; риск утечки |
